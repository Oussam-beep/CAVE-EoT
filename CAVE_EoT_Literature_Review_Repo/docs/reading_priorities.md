# Reading Priorities

This queue reflects the current handbook and should be updated as primary sources are rechecked.

## Priority 1 — Closest neighbors for the contribution boundary

1. **AgentAuditor** — reasoning-step atomization, alignment, and auditing. Compare representation, training/supervision, target and decision rule.
2. **CAGE-CAL** — matched independent/post-communication reference and learned calibration. Clarify how its output target differs from derivation overlap.
3. **DarkForest** — answer-level candidate reliability and dependence discounts. Compare answer-level versus step-/chain-level support accounting.
4. **Slim-SC** and **ARGORA** — semantic redundancy pruning and argument-graph aggregation. Test whether null calibration adds value beyond structural/semantic redundancy reduction.
5. **Great Models Think Alike and this Undermines AI Oversight** — chance-adjusted agreement and correlated errors. Be precise about the difference between dataset-level outputs and per-question support paths.

## Priority 2 — Evaluation and confounds

6. **Should we be going MAD?** — compare against well-configured simple alternatives and report cost.
7. **Talk Isn't Always Cheap** — track correct-to-wrong and wrong-to-correct changes, not accuracy alone.
8. **Let's Verify Step by Step** — separate reasoning-step correctness from derivation independence.
9. **Hear Both Sides / DAR** — distinguish message diversity and effective-sample-size motivation from derivation-level overlap.
